# Profile direction

## Register

brand

## Users

People visiting Oskar Freye's GitHub profile to see who he is and explore his work, including products whose source code is private.

## Product Purpose

Make the full public-facing body of work discoverable from the profile. Product websites belong alongside public repositories. The approved lineup has nine products and websites plus six open-source projects; platine replaces the discontinued ocgw.

## Brand Personality

Personal, technical, direct. The user chose a neofetch-style opener with an ASCII mark and factual fields. The rest of the page should show real products rather than another personal-brand introduction.

## Anti-references

The five prose-led profile drafts were rejected. Avoid generic founder taglines, badge walls, animated typing banners, remote stats cards, and an inventory of private repository names.

## Design Principles

- Open with the approved neofetch idea, not a marketing headline.
- Show the products already identified in the public portfolio, including those backed by private repositories.
- Use public website links for private-source work and source links only for verified public repositories.
- Keep project descriptions factual and brief. Do not imply that a fork is an original project.
- Keep visuals in this repository so the page does not depend on a card-rendering service.

## Accessibility & Inclusion

Use GitHub-native headings, links, and project text. Images need descriptive alternatives; essential project information must remain readable without them. Support narrow screens and both GitHub color schemes. The header and project previews are static, without animation.
